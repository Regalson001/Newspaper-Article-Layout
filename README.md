## 📌 Project Overview

**Newspaper Article Layout** is a modern digital newspaper webpage inspired by traditional editorial publications.

The project combines classic newspaper styling with a contemporary web layout. It features a publication masthead, navigation menu, featured article, author information, editorial photography, structured article content, highlighted quotations and related stories.

It demonstrates how HTML5 and CSS3 can be used to create a polished, content-focused digital publication without relying on front-end frameworks.

## ✨ Key Features

- **Editorial Masthead:** A professional newspaper title and publication identity.
- **Navigation Menu:** Clearly organised news categories.
- **Breaking News Banner:** A dedicated announcement area.
- **Featured Article:** Large headline, subtitle and editorial presentation.
- **Author Information:** Writer details and publication date.
- **Featured Photography:** Editorial image with caption and attribution label.
- **Structured Article Content:** Organised headings, paragraphs and sections.
- **Pull Quote:** Highlighted quotation for editorial emphasis.
- **Related Stories:** Additional article cards with images and descriptions.
- **Responsive Design:** Layout adapts to desktop, tablet and mobile devices.
- **Accessible Navigation:** Descriptive links, image alt text and visible keyboard focus.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/Regalson001/Newspaper-Article-Layout.git
```

### 2. Open the project directory

```bash
cd Newspaper-Article-Layout
```

### 3. Open in Visual Studio Code

```bash
code .
```

### 4. Launch the website

Open `index.html` in your preferred browser, or use the Live Server extension in Visual Studio Code.

## 📱 Responsive Design

The layout adapts to different screen sizes:

- **Desktop:** Full editorial layout with wide article content and three related-story cards.
- **Tablet:** Adjusted navigation, article spacing and two-column story cards.
- **Mobile:** Simplified masthead, compact navigation and vertically stacked content.
